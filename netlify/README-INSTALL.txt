OpeningTrainer — put it on your phone (free, no app store, no tools)

1) On a computer, go to:  https://app.netlify.com/drop
2) Drag THIS WHOLE FOLDER (all files together) onto the page.
3) Netlify gives you a link like  https://your-name.netlify.app
4) Open that link ON YOUR PHONE, then install it:
     • Android (Chrome): tap the blue "Install app" button (bottom-right),
       or menu (3 dots) -> Install app / Add to Home screen.
     • iPhone (Safari): tap Share, then "Add to Home Screen".

The same site installs on BOTH Android and iPhone — you only upload once.
After installing it opens full-screen like a normal app and works offline.
