Chess Career — install it on a PC and on a phone (free, no app store, no tools)

PUT IT ONLINE ONCE
------------------
1) On a computer, open:  https://app.netlify.com/drop
2) Drag THIS WHOLE FOLDER (all the files together) onto that page.
3) Netlify gives you an address like  https://your-name.netlify.app
   It is https, which is what browsers require before they will install a site.

THEN INSTALL IT, FROM THE APP ITSELF
------------------------------------
Open that address and press the green "Install" button in the top bar
(it is also in Settings, and in the "More" menu on a phone).

  • Windows / macOS / Linux, in Chrome or Edge
      One press installs it. It gets a Start-menu / Launchpad entry and its
      own window with no browser bars.

  • Android, in Chrome
      One press installs it, with its own icon in the app drawer.

  • iPhone / iPad, in Safari
      Apple allows no one-tap install, so the button shows the exact steps:
      Share  ->  Add to Home Screen  ->  Add.

  • Firefox on a PC has no install feature at all; the button says so and
      tells you to use Chrome or Edge. On Android Firefox: menu -> Add to
      Home screen.

Once installed it works with no internet. The only thing that still needs a
connection is Stockfish on first use (the eval bar, Game Review, playing the
engine) and reading your Chess.com games.

WHAT ELSE IS IN THE BOX
-----------------------
ChessCareer.apk               Android app, install it directly — no Netlify needed.
ChessCareer-standalone.html   The whole game in one file. Double-click it and it
                              runs offline. A file opened this way cannot install
                              itself (browsers only install real addresses), but

                              and an icon:  ⋮  ->  Cast, save and share  ->
                              Create shortcut…  ->  tick "Open as window".
